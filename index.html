Sobre el proyecto

Este proyecto ha sido realizado como práctica del módulo de Sistemas de Control de Versiones.

El objetivo de la actividad es aprender a trabajar con ramas de Git y publicar contenido mediante GitHub Pages.

Objetivos

  • Utilizar Git para controlar versiones.
  • Crear y utilizar ramas.
  • Trabajar con GitHub.
  • Publicar una página web mediante GitHub Pages.

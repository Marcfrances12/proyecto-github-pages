Mini tutorial

Inicio Tecnologías Tutorial Capturas

1. Clonar el repositorio

git clone https://github.com/USUARIO/proyecto-github-pages.git

2. Entrar en el proyecto

cd proyecto-github-pages

3. Cambiar a gh-pages

git checkout gh-pages

4. Realizar cambios

Se pueden modificar los archivos HTML y CSS.

5. Guardar los cambios

git add .
git commit -m "Actualizar documentación"
git push

6. Publicación

GitHub Pages publica automáticamente el contenido de la rama gh-pages después de configurarlo desde los Settings del repositorio.

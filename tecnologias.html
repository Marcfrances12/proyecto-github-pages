Tecnologías utilizadas

Inicio Tecnologías Tutorial Capturas

Git

Git es el sistema de control de versiones utilizado para gestionar los cambios del proyecto.

GitHub

GitHub permite almacenar el repositorio online y trabajar con ramas y versiones del proyecto.

GitHub Pages

GitHub Pages permite publicar páginas web estáticas directamente desde un repositorio de GitHub.

HTML

HTML se utiliza para crear la estructura de las diferentes páginas.

CSS

CSS se utiliza para aplicar estilos y mejorar el diseño visual.
